# Portofolio Fikri Hikam A.

Source code website portofolio pribadi **Fikri Hikam A.** — Full-Stack Web & Data Analytics, mahasiswa Sistem Informasi UNISNU Jepara.

Live: https://portofolio.tillrea.my.id

## Isi situs

- Hero dengan foto dan status kolaborasi
- Tentang & keahlian
- Portofolio proyek (termasuk Museum TillRea dan Reny HikZar Collection)
- Pendidikan — UNISNU Jepara & SMK Negeri 2 Jepara (2024)
- Pengalaman — magang di Katalis Media (optimasi website, GA4, Google Business Profile, Google Maps Business)
- Hobi & Eksperimen — agen AI, infrastruktur VPS, dan otomasi
- Kontak

## Teknologi

React 19, Vite 6, TypeScript, Tailwind CSS v4, Framer Motion, Three.js

## Menjalankan

```bash
npm install
npm run dev
npm run build
```

Hasil build di-deploy sebagai situs statis ke `portofolio.tillrea.my.id`.
